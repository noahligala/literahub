# Delivery roadmap

## Phase 0 — Validation and rights, weeks 1–2

- Confirm product name and ownership
- Inventory all resources
- Verify digital distribution rights
- Interview schools, teachers, lecturers and students
- Approve initial pricing and pilot institutions

## Phase 1 — Foundation, weeks 3–5

- Install dependencies and authentication starter kit
- Configure roles, permissions and policies
- Complete school membership model
- Establish CI, environments, backups and coding conventions

## Phase 2 — Library, weeks 6–9

- Build author/content administration
- Implement categories, levels, genres and metadata
- Add private uploads and cover processing
- Create catalogue, resource pages and entitlement checks
- Build PDF/EPUB reader proof of concept

## Phase 3 — Subscriptions and payments, weeks 10–13

- Complete plans and subscription lifecycle
- Add invoices and receipts
- Implement M-Pesa OAuth, STK Push, callbacks and verification
- Add manual bank-payment review
- Add trials, coupons and renewal reminders

## Phase 4 — School learning, weeks 14–17

- Classes and streams
- CSV user imports
- Reading lists and assignments
- Quizzes, attempts and teacher marking
- School usage and learner progress reports

## Phase 5 — Pilot and hardening, weeks 18–21

- Security and permission review
- Performance and load testing
- Pilot with 2–5 institutions
- Fix onboarding, reader and payment defects
- Prepare training and support material

## Phase 6 — Production launch, weeks 22–24

- Production migration
- School onboarding
- Support operations
- Monitoring and incident response
- First-month product and revenue review
